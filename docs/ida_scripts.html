class Pointer:

Represent an address. The Pointer class offers convenient access to read/write from a memory address.

Init a Pointer object with Pointer.__init__ or the shorthand ptr.

A Pointer object provides convenient functions to read/write certain data types (integers, floats, string, pointer) to its address in memory. These methods take an optional value parameter. They read and return the value if value is None, write and return success/failure as a bool when value is not None.

Reads come from the debugged process while one is being debugged, and from the database otherwise. Writes always go to the debugged process.

Pointer can be added/subtracted from another Pointer or int to yield a new Pointer.

class Module:

Represent a module (the executable or a library) loaded in the debugged process.

Get one with Module.find, Module.containing or Module.all_modules, or from Pointer.module.

module + offset is a Pointer into the module. Module.to_static and Module.from_static translate between the process and a database made from the module's file, which may be loaded at another base:

engine = Module.find('Engine.dll')
engine.static_base = 0x10000000      # where the database has it
ptr(engine.from_static(0x10004de0)).u32()

Base address in the process.

size: int

Size in bytes, 0 when the debugger does not know it.

Represent a member of a struct type.

A MemberT holds the member's id, so it follows the member through later changes to the struct. IDA gives the id of a deleted member to a member it creates later (the gap left in its place, for instance), so do not keep using the MemberT of a deleted member.

def add_gap(self, offset: int, size: int) -> MemberT:

Create and return a new member representing a bytes gap, _BYTE gapXX[size].

IDA keeps the holes inside a struct as gap members of that form itself, so when exactly that gap is already there, it is returned. Raises IDAError when a member that is not a gap is in the way.

def delete_member(self, member: MemberT | str) -> bool:

Delete a given member, or the member of that name. A member in the middle leaves a gap, the last one shrinks the struct.

def add_member_auto(self, declaration: str, offset: int) -> MemberT:

Create and return a new member in this struct type, automatically reworking gaps.

declaration is as for add_member, such as 'int count' or 'char name[16]'.

A gap is recognised by:

  1. Is a single or array of 'char' or '_BYTE'.
  2. Name starting with 'gap' (all lowercase).

If the new member falls within gaps of the above definition, they are split around it: what is left before and after it stays a gap, named after its offset.

Raises
  • IDAError: When a member that is not a gap is in the way (nothing changes then), or IDA refuses the member.
def to_dict(self) -> Dict[str, Any]:

The main properties as a JSON-friendly dict, addresses as hex strings.

def subtree_search_strict(self, query: Dict[str, Any]) -> List[List[List[CItem]]]:

Perform a dfs tree search with the specified query.

The query is a dict representing a subtree to search for, recursively defined as:

<query> = {
        "op" : <str>,
        "condition" : <lambda (CItem) -> bool>,
        "children" : [<query>, ...]
}

op the name of the operation for the current item condition the matching condition for the current item children nested query(ies) specifying the children to match

All fields are optional, but at least one of op, condition must be present. The query does not have to specify the complete subtree, but each of its specified level must be complete. ie. Query: { op : A, children: [{ op : B}, { op : C }]}

A Match: [[A], [B, C]]

Returns: [[[A], [B, C]], ...]
